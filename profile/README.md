## What we build

Birdeye is the intelligence layer for onchain markets. Three products, one data backbone covering **100M+ tokens** across **400+ exchanges** — all AI-ready:

| Product | For | What it is |
|---|---|---|
| 🖥️ **Birdeye Terminal** | Active traders | Real-time onchain trading terminal — token discovery, smart money tracking, wallet flows, and execution, all you need for trade validation. [birdeyeterminal.com](https://birdeyeterminal.com/) |
| ⚡ **Birdeye Data** | Developers & AI agents | Decision-grade data API & WebSocket infrastructure — the intelligence layer above raw RPCs, powering finance apps, wallets, trading bots, dApps, and autonomous agents. [birdeye.so/data-api](https://birdeye.so/data-api) |
| 📊 **Birdeye Peak** | Institutions | Institutional-grade onchain terminal — unified market data, deep analytics, portfolio & risk management, and AI-assisted research for professional capital allocators. [Request access](https://birdeye.so/peak) |

## For developers & AI agents

**Birdeye Data** is the onchain data layer for apps, bots, and autonomous agents — prices, liquidity, DEX trades, smart-money & wallet intelligence, token security, and real-time streams.

**What you can build**
- 🧠 Smart money / smart wallet tracking
- 🐋 Whale & large-transaction alerts
- 💼 Wallet portfolio, PnL & trading-style analysis
- 🔎 Token discovery — trending, new pairs, meme lists
- 📈 Price, OHLCV, liquidity & DEX trade data
- 🛡️ Token security & rug checks
- 🔌 Real-time WebSocket streams

Connect via REST, the hosted **MCP server**, or pay-per-request **x402** — plus 20 ready-made **Agent Skills** in [`birdeye_cli`](https://github.com/birdeye-so/birdeye_cli).

📖 [Docs](https://data.birdeye.so/docs) · 🤖 [Agent setup (MCP / x402)](https://data.birdeye.so/docs/agents/overview) · 🔑 [Get an API key](https://birdeye.so/data-api)
